# hangar
Simple, web-based and self-hosted file cloud

# Development
hangar is divided in the following crates:
- [hangar-server](https://github.com/itsgerliz/hangar/tree/master/crates/hangar-server/) - The hangar server
- [hangar-core](https://github.com/itsgerliz/hangar/tree/master/crates/hangar-core/) - The engine behind the hangar server
- [hangar-cli](https://github.com/itsgerliz/hangar/tree/master/crates/hangar-cli/) - The hangar command line client

# Contributing
Contributions will be accepted when hangar reaches its first stable version (`1.0.0`)
